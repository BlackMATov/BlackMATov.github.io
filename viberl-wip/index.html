The game needs WebGL, and this browser could not start it.

WebGL is the browser's 3D graphics. It is turned off or failed to start here. Things that usually help:

  • Firefox on Windows: open about:config, set webgl.disable-angle to true and restart the browser.
  • Turn on hardware acceleration in the browser settings (Firefox: Settings → General → Performance; Chrome and Edge: Settings → System).
  • Check that WebGL is not disabled: webgl.disabled in Firefox's about:config, or a privacy extension that blocks it.
  • Update the video card driver from the vendor's site (NVIDIA, AMD, Intel).
  • Try another browser.

To check WebGL on its own, open get.webgl.org: it shows a spinning cube when WebGL works. Firefox explains why it failed in about:support, under Graphics.
